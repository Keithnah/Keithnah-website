Buying in TRX: common questions

How many new launch projects are there in TRX?

Keith currently lists 2 projects in TRX: Core Residence, Golden Crown Residence.

What is the lowest starting price for a new property in TRX?

The lowest published starting price is about RM1,280,000 (gross) at Golden Crown Residence. Prices change with each phase and unit; ask Keith for the latest figures.

Are there freehold projects in TRX?

Yes. Freehold projects here include Core Residence.

When will the new projects in TRX be completed?

Expected completion ranges from 2024 to 2026, depending on the project. Some projects complete a set number of months after the advertising permit (APDL).

Can foreigners buy property in TRX?

Yes. Foreign buyers in Kuala Lumpur must meet the state minimum purchase price, currently RM1 million for most residential property types, and need state consent.
