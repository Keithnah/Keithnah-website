MABA Suitez は買い？購入者向けのわかりやすいガイド

2026年11月14日 · Keith Nah

MABA Suitez は Jalan Hang Jebat にある2棟のサービスアパートメントで、Menara Merdeka Maybank のすぐ隣、Merdeka MRT から約160mです。プロジェクトの内容、向いている購入者、決める前に比較したい点をまとめました。

MABA Suitez とは

MABA Suitez は EXSIM とマレーシア・バスケットボール協会（MABA）が共同で開発し、敷地は MABA の旧ビルの場所です。2棟で計914戸、A棟は54階、B棟は50階、敷地は1.328エーカーです。

2025年11月末に起工し、2031年の完成が見込まれています。MABA の新本部もこの建物に入り、3x3バスケットボール用のハーフコートがあります。6階のポディウムには住民用のバスケットボールコートもあります。

立地とアクセス

立地はこのプロジェクト最大の強みです。Kajang 線の Merdeka MRT 駅まで約160m、徒歩約2分。そこから Pavilion Kuala Lumpur まで1駅、TRX と KL Sentral（Muzium Negara 経由）まで2駅です。

周辺には Merdeka 118 と Menara Merdeka Maybank、Stadium Negara、Pasar Seni、旧市街があり、KL City Centre も近くです。

間取りと価格

主な間取りは3つ：Type A は323平方フィートのオフィススイート、Type B は484平方フィートの1+1ルーム、Type C は657平方フィートのデュアルキーで1部屋・バス2つ。価格は RM699,000（グロス）からで、平方フィート単価は約 RM2,164 – RM2,701 です。

最も多いのは Type C の377戸で、Type B が288戸、Type A が249戸です。スカイ施設は B棟の47階と50階、A棟の53階から53A階にあります。

向いている購入者

MABA Suitez は、手頃な価格から MRT 隣の都心物件を持ちたい投資家、KL 中心部に小さなオフィスが欲しい経営者、コンパクトな住まいを求める単身者やカップルに向いています。デュアルキーの Type C は、片方に住みもう片方を貸すなど柔軟に使いたいオーナーに向いています。

決める前に比較したい点

住戸は323〜657平方フィート、最大1部屋とコンパクトなので、部屋数が必要なご家族は他のプロジェクトの広い間取りも見てみるとよいでしょう。リースホールドで、駐車場は住戸と別売り、管理費は平方フィートあたり RM0.99（Type A で月約 RM320）です。

外国人購入者のクアラルンプールでの最低価格は100万リンギットです。入門住戸はこれを下回りますが、広い住戸は条件を満たせるので、予約前に実際の住戸を確認してください。
