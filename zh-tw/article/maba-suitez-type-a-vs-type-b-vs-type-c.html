MABA Suitez 選 Type A、B 還是 C？哪個戶型適合你

2026年11月14日 · Keith Nah

MABA Suitez 有三種主要戶型，從 323 平方尺的辦公室套房到 657 平方尺的雙鑰匙套房。不同戶型適合不同的計劃，這篇把面積、單位數量和每月開銷放在一起比較。

Type A：323 平方尺辦公室套房

Type A 是開放式格局，有小廚房和 1 間浴室，是這個項目的入門單位，RM699,000 起（Gross）。兩棟樓共有 249 個 Type A。

適合想在市中心有一間小辦公室的老闆，或想用最低入場價做第一個城市投資的買家。管理費每月約 RM320。

Type B：484 平方尺，1+1 房

Type B 是 484 平方尺、1+1 房、1 間浴室，共有 288 個單位。多出來的小房間可以當書房、工作區或小客房。

適合想要獨立房間的單身專業人士或情侶。管理費每月約 RM479。

Type C：657 平方尺雙鑰匙

Type C 是雙鑰匙套房，657 平方尺，有客廳和飯廳、1 間房、2 間浴室。這是數量最多的戶型，有 377 個單位，另外還有左右對調的 Type C (M)。

雙鑰匙單位有兩個門，業主可以自住一邊、出租另一邊，或兩邊都出租。管理費每月約 RM650。

每月開銷：以 Type A 為例

以 RM699,000、貸款 90%、35 年、利率 4.2%（只是例子）計算，每月供期約 RM2,861。加上每月約 RM320 的管理費，每月開銷約 RM3,181。實際利率請以銀行為準。

Type B 和 Type C 的價格要看樓棟和樓層。喜歡哪個單位，可以 WhatsApp Keith 查最新價格。

怎麼選

想要最低入場價或市中心辦公室，選 Type A；想要自己的獨立房間，選 Type B；想要兩個門的彈性，選 Type C。不管選哪個，下訂前都要確認實際單位、樓層和價格。
